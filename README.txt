# Crimson Cut — GitHub Pages starter

## Files
- `index.html` — complete responsive website (HTML, CSS and JavaScript in one file)
- `assets/brand-post.png` — your uploaded Crimson Cut post, included as a visual reference

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `crimson-cut-portfolio`).
2. Upload `index.html` and the `assets` folder to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub to publish the site. The Pages URL will appear in that section.

## Customize before publishing
In `index.html`, search for and replace:
- `hello@yourdomain.com` with your business email.
- The `href="#"` social links with your real profile URLs.
- The three project placeholder cards with your actual portfolio links and thumbnails.
- Service descriptions if you want to adjust the wording.

The Google Fonts import requires an internet connection. The site still has Georgia/Arial fallbacks if the fonts cannot load.
